Training brains against new brains

Did each model really learn what a tumour looks like, or did it just memorise the brains it studied? To find out, the finished model outlines three groups of brains, and we compare its average score on each. Hover a score to see it per tumour region.

How to read this table

The three groups of brains

Think of the model as a student preparing for an exam.

  • Training brains: the practice questions, with the answers. The model learned from these: it saw each one, together with the expert's outline, many times during training.
  • Validation brains: a mock exam. The model never learned from them; they were only used to decide which saved version of the model to keep (the one that scored best on them).
  • Test brains: the real final exam. Not used for anything until the very end, so the model had never seen them.

The numbers

  • Each score is the average Dice when the model outlines every brain in that group. Dice measures how well the model's outline overlaps the expert's: 1 is a perfect match, 0 no overlap at all.
  • All three groups are scored in exactly the same way (whole brains, the same settings), so the scores can be compared directly.
  • Gap = score on the training brains minus score on the test brains.

What the gap tells you

  • Small gap (a few hundredths): the model does almost as well on brains it has never seen as on the ones it studied. It learned general patterns of what tumours look like, so it should work on new patients.
  • Large gap (say 0.99 on training brains but 0.70 on test brains): the model memorised its training brains instead of learning. This is called overfitting, and such a model would disappoint on new patients.
